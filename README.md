# dotfiles

Personal dotfiles for macOS — shell config, Python/ML environment setup, and developer tooling.

## What's in here

| File | Symlink target | Purpose |
|------|---------------|---------|
| `bash_profile` | `~/.bash_profile` | Login shell: PATH, Homebrew, sources bashrc |
| `bashrc` | `~/.bashrc` | Interactive shell: aliases, history, fzf, starship, direnv |
| `direnvrc` | `~/.config/direnv/direnvrc` | Global direnv layout: uv venv + Jupyter kernel auto-registration |
| `direnv-config.toml` | `~/.config/direnv/config.toml` | Whitelist: auto-allows `.envrc` under `~/workspace` |
| `ghostty-config` | `~/.config/ghostty/config` | Ghostty terminal: bash 5 login shell, FiraCode Nerd Font, Gruvbox Dark, transparency |
| `agents-global.md` | `~/.config/opencode/AGENTS.md` | Behavioral guidelines + RTK usage, loaded into every opencode session |
| `RTK.md` | `~/.config/opencode/RTK.md` | Standalone rtk proxy reference (opencode V2 ignores `instructions`; the loaded copy lives in `agents-global.md`) |
| `opencode.jsonc` | `~/.config/opencode/opencode.jsonc` | opencode V2 config: default model, agent variants, MCP servers |
| `plugins/rtk.ts` | `~/.config/opencode/plugins/rtk.ts` | opencode V2 plugin: rewrites shell commands through rtk |

`AGENTS.md` is repo-local project context for AI tools working in this repo.

## Fresh machine setup

### 1. Prerequisites

```bash
# Install Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install core tools (tlrc is the maintained replacement for the deprecated tldr formula)
brew install bash bash-completion@2 fzf starship direnv node ripgrep fd bat eza zoxide tlrc rtk ast-grep
brew install --cask ghostty

# Install the opencode V2 CLI
brew install anomalyco/tap/opencode-v2

# Install uv (standalone)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install uv-managed Python as the global default (~/.local/bin shims)
uv python install 3.13 --default
```

### 2. Switch to Homebrew bash

```bash
sudo sh -c 'echo /opt/homebrew/bin/bash >> /etc/shells'
chsh -s /opt/homebrew/bin/bash
```

### 3. Clone and symlink dotfiles

```bash
git clone https://github.com/varunsamtani3/dotfiles.git ~/workspace/dotfiles
cd ~/workspace/dotfiles

ln -s "$PWD/bash_profile" ~/.bash_profile
ln -s "$PWD/bashrc" ~/.bashrc
mkdir -p ~/.config/direnv
ln -s "$PWD/direnvrc" ~/.config/direnv/direnvrc
ln -s "$PWD/direnv-config.toml" ~/.config/direnv/config.toml
mkdir -p ~/.config/ghostty
ln -s "$PWD/ghostty-config" ~/.config/ghostty/config
mkdir -p ~/.config/opencode/plugins
ln -s "$PWD/agents-global.md" ~/.config/opencode/AGENTS.md
ln -s "$PWD/RTK.md" ~/.config/opencode/RTK.md
ln -s "$PWD/opencode.jsonc" ~/.config/opencode/opencode.jsonc
ln -s "$PWD/plugins/rtk.ts" ~/.config/opencode/plugins/rtk.ts
```

### 4. Install global uv tools

```bash
uv tool install jupyterlab   # required for Jupyter kernel auto-registration in direnvrc
uv tool install ipython
uv tool install ruff
uv tool install gitingest    # packs a repo into a single LLM-ready text block
```

### 5. Configure git

```bash
git config --global user.name "Varun Samtani"
git config --global user.email "varunsamtani3@gmail.com"
git config --global credential.helper osxkeychain
```

### 6. Set up AI token optimization (rtk)

`rtk` is a CLI proxy that filters/summarizes command output before it reaches LLM context (60-90% savings). The plugin at `~/.config/opencode/plugins/rtk.ts` (symlinked from step 3) rewrites shell commands through `rtk hook opencode` (`git status` -> `rtk git status`), checking each rewrite against OpenCode's permission rules — zero token overhead.

It is the V2 plugin generated by rtk itself (rtk >= 1.0.0), vendored here. Refresh it after an rtk upgrade (this writes through the symlink into this repo):

```bash
rtk init -g --opencode
```

RTK usage guidance is folded into `agents-global.md` (loaded as `AGENTS.md`) because opencode V2 ignores the `instructions` config field.

Useful commands:

```bash
rtk gain              # token savings dashboard
rtk proxy <cmd>       # run a command without rtk filtering (debugging)
```

### 7. Set up GitHub MCP for opencode

`opencode.jsonc` points at GitHub's official remote MCP server (`https://api.githubcopilot.com/mcp/`) using OAuth — no personal access token required. The deprecated `@modelcontextprotocol/server-github` npm package is no longer used.

```bash
opencode mcp list          # expect: github  needs authentication

# In opencode: run /mcps, select github, and complete the OAuth sign-in.
# Credentials are stored by opencode outside this repo; nothing to manage here.
```

To use a token instead of OAuth, set `"oauth": false` and add
`"headers": { "Authorization": "Bearer {env:GITHUB_PERSONAL_ACCESS_TOKEN}" }` to the github server entry.

## New project workflow

```bash
mkdir ~/workspace/my-project && cd ~/workspace/my-project
git init
echo "3.13" > .python-version       # pin Python version
echo "layout uv" > .envrc           # auto-creates .venv + registers Jupyter kernel
direnv allow
uv pip install <packages>
```

direnv will automatically:
- Create `.venv` using Python 3.13
- Activate it on `cd` in, deactivate on `cd` out
- Register the project as a Jupyter kernel (named after the folder)

- **Experiment tracking**: MLflow
- **Data tools**: polars, duckdb
- **LLM clients**: anthropic, openai, litellm
- **Code quality**: ruff
- **AI token optimization**: rtk proxy via opencode plugin, ast-grep, gitingest
